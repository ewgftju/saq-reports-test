# SAQ — Отчет и Аналитика

Рабочий демонстрационный модуль на вымышленных данных. Общая шапка, меню, логотип и цветовая схема взяты из `ewgftju/saq-prof-control-demo`. Система относится к проекту SAQ.

## Возможности

- Четыре формы по предоставленным Excel: органы аудита (228 колонок), дела ВГА (247), дела ЭГА (242), АБП / бюджетные программы (111).
- Дополнительные отчеты по СУР, СВА, профилактическому контролю и возражениям.
- Период по отчетной дате, регион, орган, статус, поиск, формат и тип аудита, включение в отчетность, порог суммы, риск, решение и просрочка.
- Конструктор: пять источников, выбор и порядок полей, группировка по модулю, региону, органу и месяцу.
- Предпросмотр, сортировка, страницы, детализация, Excel OOXML, CSV, печать.
- Полная структура исходных форм: колонки, исходные подписи и объединения шапки. Не является воспроизведением всех исходных стилей и формул.
- Шаблоны и снимки последних 20 результатов в localStorage текущего браузера.
- Аналитика с детализацией до записей.

## Запуск и проверка

Node.js 22+; внешних зависимостей нет.

```sh
npm test
npm run build
```

Статические файлы из `dist/` можно обслуживать любым HTTP-сервером. Vercel: `npm run build`, output `dist`, framework Other. Настройки находятся в `vercel.json`.

## Данные и ограничения

В `data.js` только синтетические записи. Данные, БИН, суммы, имена и результаты из приложенных файлов не публикуются. `templates.js` содержит исключительно заголовки и объединения шапок, извлеченные из образцов. В каждой выгрузке указано, что данные демонстрационные.

API пяти модулей, серверная авторизация, фоновые задания, общая история и официальная методика расчета пока не подключены. Пользовательские настройки хранятся только в браузере. Нельзя использовать демо для официальной отчетности.

Полная Excel-форма заполняется только теми показателями, которым сопоставлены поля демонстрационного набора. Остальные ячейки пустые, а лист «Состав формы» перечисляет их статус. Ноль не заменяет отсутствие данных. В исходных образцах есть неоднозначные/повторяющиеся подписи; они сохранены для согласования с заказчиком.
