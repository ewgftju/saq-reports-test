# SAQ — Отчет и Аналитика

Рабочий демонстрационный модуль на вымышленных данных. Общая шапка, меню, логотип и цветовая схема взяты из `ewgftju/saq-prof-control-demo`. Система относится к проекту SAQ.

## Возможности

- 32 действующие Excel-формы, 41 лист: 19 форм УАО, 6 форм перечня/поручений/электронного аудита/контроля качества, 6 форм профилактического контроля и отчет СВА ЦГО/МИО/ДП. АБП — 274 колонки, ВГА — 270, органы аудита — 258, ЭГА — 242.
- Дополнительные отчеты по СУР, СВА, профилактическому контролю и возражениям.
- Период по отчетной дате, регион, орган, статус, поиск, формат и тип аудита, включение в отчетность, порог суммы, риск, решение и просрочка.
- Прямая кнопка «Выгрузить всё» и независимая настройка выбранных колонок; выбор полей не обязателен.
- Предпросмотр, сортировка, страницы, детализация, Excel OOXML, CSV, печать.
- Полная структура исходных форм: колонки, исходные подписи и объединения шапки. Не является воспроизведением всех исходных стилей и формул.
- Конструктор, шаблоны, история и источники скрыты; код сохранен под флагами функций.
- Аналитика с детализацией до записей.

## Запуск и проверка

Node.js 22+; внешних зависимостей нет.

```sh
npm test
npm run build
```

Статические файлы из `dist/` можно обслуживать любым HTTP-сервером. Vercel: `npm run build`, output `dist`, framework Other. Настройки находятся в `vercel.json`.

## Данные и ограничения

В `data.js` только синтетические записи. Данные, БИН, суммы, имена и результаты из приложенных файлов не публикуются. `templates.js` содержит исключительно заголовки и объединения шапок, извлеченные из образцов. Учебный характер данных указан в интерфейсе; дополнительные служебные листы в Excel не добавляются.

API пяти модулей, серверная авторизация, фоновые задания, общая история и официальная методика расчета пока не подключены. Пользовательские настройки хранятся только в браузере. Нельзя использовать демо для официальной отчетности.

Полная Excel-форма заполняется только теми показателями, которым сопоставлены поля демонстрационного набора. Остальные показатели отмечены «Нет данных». Ноль не заменяет отсутствие данных. В исходных образцах есть неоднозначные/повторяющиеся подписи; они сохранены для согласования с заказчиком.

Подробный план подключения и правила гранулярности — в [INTEGRATION.md](./INTEGRATION.md).

## Обновление 18.10.2026

Excel без закрепления строк/столбцов и баннеров. Доступны выбранные показатели, полная исходная шапка и полная плоская таблица для фильтрации. Нули, отсутствие и неприменимость различаются.

В конструкторе кнопка «Пример: ВГА + СУР + Возражения» включает связанный набор. Три вымышленных дела, два из них с одним БИН; расчёты СУР привязаны явно. Детализация номера дела показывает исходные нарушения, исполнения, возражения и отмены. Сохранение шаблона и истории сохраняет выбранный набор.

Общий список пяти модулей остаётся отдельным режимом, без произвольного соединения по БИН. В разделе «Источники данных» приведены пробелы четырёх новых форм заказчика.

## Ограничения конструктора — 19.10.2026

Пользователь сначала выбирает набор данных. Общий ключ не выбирается вручную.

- `module`: ровно один источник и только его поля/фильтры.
- `registry`: выбранные модули идут отдельными строками; только общие реквизиты, при группировке — количество записей и объектов. Финансовые показатели, риск и решения не объединяются.
- `case-links`: фиксированный состав ВГА + СУР + Возражения и подготовленные связи. Произвольное добавление модулей запрещено.

«Выбрать все доступные» использует каталог выбранного набора. Проверка выполняется также перед формированием, сохранением и скачиванием. Несовместимый старый шаблон открывается с очищенными параметрами и объяснением. Несовместимый снимок истории требует нового формирования; исходный снимок не перезаписывается. Из аналитики в общий реестр переносятся счетчики, а не разнотипные финансовые показатели.

## Выбор колонок при выгрузке — 19.10.2026

Кнопка «Настроить выгрузку» открывает отдельное окно с поиском, разделами и списком колонок. В готовой форме можно выбрать любые именованные колонки полного исходного образца либо только поля текущей таблицы. Для конструктора список ограничен полями сформированного результата.

По умолчанию в полной форме отмечены колонки с сопоставленным источником. Это не гарантирует заполнение каждой строки; неподключенные колонки явно отмечены и дают «Нет данных». Поиск и выбор раздела не снимают ранее отмеченные поля. Excel/CSV содержат только выбранные колонки, все строки текущего результата и прежние условия отбора. Порядок соответствует исходной форме или текущей таблице. Выбор сохраняется в этом браузере после скачивания.

Выгрузка целой формы вынесена в отдельный свернутый блок и явно включает все колонки. Выбранный Excel содержит плоскую шапку без закрепления строк и дополнительных листов. Данные невыбранных колонок в другие листы не попадают.

Для отчета ВГА + Возражения можно открыть связанный пример и исключить поля «Связанный расчёт СУР» и «Уровень риска» при выгрузке. Связи возражений с делами и денежные расчеты сохраняются.

## Все формы архива и упрощение интерфейса — 20.10.2026

Этот раздел заменяет описание предыдущего каталога и прежнего размещения кнопки полной выгрузки.

Исходная редакция включала 72 логические позиции и 23 Excel-файла УАО. Действующая редакция от 30.10.2026 сохраняет 72 позиции по 10 управлениям: исключены №11 и №16 УАО и добавлены №20/21 управления координации. В списке 81 строка, из них 36 формируются (32 Excel-формы и 4 дополнительных отчета). Позиции без образца остаются в перечне.

`archive-schemas.js` хранит только структуру: все шапки, объединения, статические критерии и нормативные баллы. Повторяющиеся строки и узлы упакованы без потерь для уменьшения загрузки. Фактических строк заказчика нет. Воспроизведение из исходного архива: `python scripts/extract-archive-forms.py /path/to/УАО.zip archive-schemas.js` (openpyxl и доступная конвертация .xls).

`archive-engine.js` формирует снимки всех листов, `archive-demo-data.js` содержит явно учебные события. Они показывают работу связей и не подтверждают наличие аналогичных полей в рабочей БД. Для неизвестных показателей остается «Нет данных», ноль сохраняет самостоятельный смысл. Рейтинговые оценки и места без утвержденной методики не вычисляются; формулы исходных книг не исполняются.

Остатки учитывают дела до начала периода и подтвержденные исполнения/отмены на дату окончания. В годовой форме движения отчетного периода отделены от остатка на дату. Исторические графы 2024–2025 не заполняются значениями 2026 года. Четыре направления исполнения не дублируются через дочерние записи.

«Выгрузить всё» сохраняет все листы и колонки с исходной шапкой. «Настроить выгрузку» предлагает поиск и выбор колонок по листам; выборочный Excel имеет плоскую шапку. В CSV допускается один лист. Ни одна выгрузка не закрепляет строки/столбцы и не вставляет баннер над таблицей. Учебный характер данных указан в интерфейсе. В выгрузке нет дополнительных листов «Параметры» и «Состав формы».

### Возврат конструктора

В `feature-flags.js` установить `builder: true` и повторно собрать/опубликовать приложение. Сохранены все три набора конструктора и их ограничения. Остальные флаги (`saved`, `history`, `sources`) независимы и остаются `false`. При выключенных функциях пункты меню, связанные кнопки и прямые переходы закрыты; ранее сохраненные настройки браузера не удаляются, новая история не записывается.


## Навигация и сравнение аналитики — 28.10.2026

Все 10 управлений доступны непосредственно в левом меню «Отчет и Аналитика». Выбор управления открывает его отчеты; «Все отчеты», дополнительные отчеты и общая «Аналитика» остаются доступными. Поиск и фильтр доступности работают внутри выбранного управления. Выбор другого управления очищает предыдущий поиск и фильтр доступности.

Аналитика поддерживает аналогичный период предыдущего года, произвольные два периода и просмотр без сравнения. Можно выбрать несколько органов аудита, сравнить их между собой и по годам. СВА и ДВГА сохраняют отдельные наименования. Регион, модули, статус и поиск одинаковы для обоих периодов. Показаны количество записей и уникальных объектов, охват, финансовые нарушения, устраненная сумма и доля устранения; таблица и диаграмма используют выбранный показатель. Изменение доли выражено в процентных пунктах. При нулевой базе относительное изменение не рассчитывается; отсутствие денежных данных не подменяется нулем. Суммы относятся только к ВГА, СВА и ПРОФ. Объекты определяются по уникальному БИН, их количества по группам не складываются.

`analytics-data.js` добавляет отдельные синтетические записи за январь–сентябрь 2025 года к учебным данным 2026 года. Исходный `data.js` и наборы архивных Excel-форм не изменены. Переход из аналитики к записям сохраняет основной период и выбранные органы, включая исторические учебные записи. Рабочие исторические данные и серверные интеграции по-прежнему не подключены.

Проверки: `npm test`, `npm run build`; расчеты периодов, 29 февраля, нулевой базы, отсутствующих значений и нескольких органов покрыты `tests/analytics-engine.test.mjs`.


## Исправление соответствия образцам — 30.10.2026

Для шести новых форм и шести форм профконтроля полная выгрузка использует исходную сетку: названия листов, заголовки, нумерацию, объединения, размеры и параметры печати. Шаблоны содержат только разрешенную статическую структуру, без фактических строк заказчика. Выбранные периоды и сформированные данные подставляются в эту сетку. Справочник КоАП не добавляется листом в административный отчет; лишний итог административной формы удален.

Во всех таблицах интерфейса и Excel применяется Times New Roman. Другие шрифтовые свойства исходных новых форм сохраняются. `template-export.js` выводит сетку, подготовленную движком, без добавления полей или служебных листов.


Первый отчет Управления по взаимодействию с органами государственного аудита — «Итоги деятельности СВА (приложение 1)», образец «Итоговая 4 ЦГО, МИО и ДП .xlsx». Сохраняет четыре листа ЦГО, МИО, ДП, ИТОГО; реальные показатели и подписи из файла в демонстрацию не переносятся. Данные СВА агрегируются по явно указанной категории и строке учреждения; сводный лист берет те же итоги. Плановые и кадровые показатели требуют отдельных фактов учреждения, отсутствующие данные не заменяются нулем.
